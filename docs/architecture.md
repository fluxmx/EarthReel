# 架构与功能边界

## 当前定位

EarthReel 是 Python 包和命令行工具，将全球规则经纬网格上的温度或速度分量生成三维地球 PNG 与 MP4。
视频固定一个数据时刻，让相机匀速环绕；双球视角严格相反，复用同一数据、球面几何和颜色表。
功能总览和已验证的数据场景见 [README](../README.md#当前功能)，配置细节见 [示例说明](../examples/README.md)。

## 已实现的模块

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 配置 | `src/earthreel/config.py` | 解析 YAML、解析相对数据路径，校验变量、时间、色标、布局、相机和输出参数 |
| 数据 | `src/earthreel/data.py` | 识别 NetCDF/GRIB，筛选变量及一个时次，转换温度单位，整理坐标和缺测，校验全球规则网格 |
| 场景与输出 | `src/earthreel/render.py` | 建立闭合球面和底球，添加图层、标注与色标，控制相机并输出 PNG/MP4 和运行记录 |
| 命令行 | `src/earthreel/cli.py` | 提供 `snapshot`、`render`、参数覆盖、覆盖保护、进度和错误提示 |

数据读取使用 xarray；NetCDF 使用 netCDF4，GRIB 使用可选 cfgrib/ecCodes。
GRIB 通过文件头识别，按 CF 变量名筛选，不在数据目录写 `.idx` 索引。
`load_field` 返回 `ScalarField`，携带坐标、显示数值、时间、原始单位、名称和显示单位；
`load_temperature` 与 `TemperatureField` 保留为温度兼容接口。
场景使用 PyVista/VTK；视频编码使用 imageio-ffmpeg 提供的 FFmpeg。

## 数据与显示约定

- 输入为单文件、一个标量变量；空间坐标是一维纬度和经度。变量支持二维单时次或三维时间序列，未选择的额外维度报错。
- 网格必须规则并覆盖全球。纬度升降序和不同经度约定会随数值同步整理，经度周期连接；只移除数值一致的重复周期端点。
- 温度支持 K 和常见 °C 单位，显示为 °C；速度分量支持 m/s，数值保持不变。其他物理单位尚未接入。
- GRIB 默认使用 `valid_time` 标注有效时间。当前只选择单个时次，不拼接多个文件或处理跨时次累计量。
- 默认 `nearest` 模式每个源格点对应一个恒定颜色单元，不降采样、不平均极区值；可选 `linear` 模式使用顶点插值并平均极区行。
- 科学图层关闭光照。科学图层与色标共用颜色表，整段视频固定色标；`vmin` / `vmax` 手动指定，`vcenter: null` 为线性映射，指定中心时采用双色归一化。
- 超范围只影响颜色，原始数值不截断。缺测保留并显示为灰色，不作为零值。
- 速度分量以正负颜色显示；目前没有合成流速、方向箭头、流线或粒子动画。

## 输出与复现

`snapshot` 导出 PNG；`render` 导出 H.264 / yuv420p MP4。默认 1440p、60 fps、20 秒，支持修改尺寸、帧率、时长、CRF 和编码 preset。
相机完成一周环绕，最后一帧不重复首帧；支持单球或双球布局。
屏幕标注包含 logo、变量标题、UTC 时间、色标与单位；来源和授权写入配置及 JSON。

每个产物附 `.png.json` 或 `.mp4.json`，记录实际配置、源数据 SHA-256、数据时刻、网格大小、
单位、有效值范围、缺测数量、显示处理、软件版本和编码参数。`valid_range` 使用显示单位，温度另保留 `valid_range_c`。
播放或分享视频只需 MP4；JSON 用于追溯与复现。

输出先写临时目录，成功后发布；已有文件默认拒绝覆盖，需显式 `--overwrite`。
新数据和生成产物默认由 Git 忽略，只有明确指定的数据才手动跟踪。

## 已验证场景与检查

现有配置覆盖 ERA5 t2m、ERA5 SST、IFS t2m、IFS SVE 和 IFS SVN；实测输入网格包括 ERA5 0.25° 与 IFS 0.1°。
ERA5 t2m 随仓库提供，其他数据由本地下载。

测试覆盖配置和命令行、坐标与单位、缺测、经度接缝、极区、真实 GRIB 合成文件解码、球面几何、
PNG/短 MP4、双视角、运行记录和覆盖保护。CI 在 Python 3.11 / 3.13 检查包，并在 Linux 软件渲染环境检查媒体输出。

## 尚未实现

- 数据随时间演变、多文件时间序列和额外层次选择。
- 区域网格、非规则高斯网格、二维曲线网格与 ICON 原生非结构网格。
- 压缩 GRIB 直接读取，Zarr/HDF5/CSV 专用入口、内存 DataArray 接口和在线下载。
- 任意物理单位、多变量叠加、矢量箭头、流线、粒子及体积云。
- 自动分位数色标、交互预览、GUI 和网页交互。

后续按实际场景扩展数据、网格与时间控制；当前不将这些能力视为已有功能。
